# Security policy

Please do not report suspected vulnerabilities by creating a public issue or pull request containing exploit details, credentials, patient information, or sensitive operational data.

Maintainers should enable GitHub private vulnerability reporting and security advisories, and verify that an appropriate private reporting channel is available. Use that private channel for security reports. If it is unavailable, contact the repository maintainers through a non-public channel listed on their verified profile. Do not include sensitive data in the report; provide the minimum safe reproduction details.

No live patient information or production credentials should ever be placed in this repository.
