# Architecture approval status

**Status date:** 5 November 2026  
**Decision:** Founder-approved architecture baseline — architecture scope only.

The Project Founder has approved Jano Health’s consolidated architecture direction and design baseline. This is a project founder decision, not an independent design-authority, clinical, legal/privacy, security, regulator, partner, facility, implementation, verification or release approval.

The architecture may guide further detailed design, engineering planning and controlled test preparation. Clinical and operational use remains prohibited until the responsible qualified authorities approve the intended workflow, risks, operating conditions and validation evidence.

The public repository intentionally does not publish the internal architecture package, detailed identity/security designs, threat models, patient-safety registers, offline-operation controls, API contracts or internal gap/approval registers.

The architecture approval does not assert that clinical tests, security tests, interoperability tests, usability tests, recovery exercises or field evaluations have been executed or passed.
